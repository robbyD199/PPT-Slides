# Folienbibliothek – PowerPoint-Add-in

Persönliche Folienbibliothek im Seitenbereich (ähnlich think-cell): Vorlagenfolien nach Kategorien mit Vorschau,
Stichwortsuche (DE/EN) und Einfügen mit einem Klick direkt hinter der aktuellen Folie – mit Master, Farben und
Schriften der Zielpräsentation.

- Installation & Bedienung: [docs/INSTALL.md](docs/INSTALL.md)
- Kategorien & MECE-Logik: [docs/TAXONOMIE.md](docs/TAXONOMIE.md)
- Stand, bekannte Einschränkungen: [PROGRESS.md](PROGRESS.md)
- Letzter Selbsttest: [test-results/report.md](test-results/report.md)

Vorlage: `templates/Library.pptx` → `scripts/update-templates.ps1` → `assets/library/` → GitHub Pages
(<https://robbyd199.github.io/PPT-Slides/>).
